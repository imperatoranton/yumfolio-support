твоя книга

рецепты, фото, папки и список покупок хранятся на устройстве. если iCloud доступен, они синхронизируются с личным хранилищем твоего Apple Account. разработчик не имеет доступа к содержимому книги в iCloud.

фотографии

Yumfolio получает только те фотографии, которые ты выбираешь через системное окно. камера не используется.

сохранение и удаление

синхронизация выполняется, пока приложение открыто, и требует интернета и свободного места в iCloud. на новом устройстве с тем же Apple Account восстановятся только данные, которые успели сохраниться в облаке. удаление приложения не удаляет облачную копию. удаление отдельных записей внутри приложения передаётся на другие устройства при синхронизации.

реклама и аналитика

в приложении нет рекламы, аналитики и отслеживания. содержимое книги не продаётся и не передаётся разработчику.

обращения в поддержку

если ты пишешь нам по электронной почте, мы получаем твой адрес и содержимое письма, чтобы ответить и разобраться в вопросе. не присылай пароли и другую информацию, которая не нужна для помощи. по этому же адресу можно обратиться с вопросом о данных или удалении переписки.

внешние сервисы

iCloud работает по правилам Apple. сайты и приложения, открываемые по ссылкам из рецептов, имеют собственные правила конфиденциальности. этот сайт размещён на GitHub Pages: GitHub может обрабатывать технические данные посетителей по своей политике. на наших страницах нет сторонней аналитики или форм сбора данных.
